CatLocker — небольшая Windows-утилита для быстрой блокировки клавиатуры или клавиатуры вместе с мышью. Управление выполняется через трей и глобальную горячую клавишу (по умолчанию `Ctrl+Shift+L`, настраивается).

## Что уже умеет

- **Блокировка ввода** — режимы `Keyboard only` и `Keyboard + mouse`.
- **Настраиваемый хоткей** — любая комбинация `Ctrl/Shift/Alt + (A–Z, 0–9, F1–F12)` с защитой от пустых модификаторов; chord детектируется внутри хука и проглатывается, чужие приложения его не видят.
- **Разблокировка** — повторное нажатие хоткея, tray-меню или двойной клик по иконке.
- **Оверлей** — pill-баннер поверх остальных окон, на экране с курсором, скрыт из Alt+Tab.
- **Тач-барьер** — в режиме `Keyboard + mouse` на всех экранах поднимаются невидимые topmost-формы, которые съедают клики/тапы (тач и перо идут мимо `WH_MOUSE_LL`). Отключается в настройках.
- **Watchdog хука** — heartbeat UI-потока + авто-переустановка хуков, если Windows молча сняла их после подвисания; в трей прилетает предупреждение.
- **Таймеры** — auto-lock после N минут простоя, auto-unlock через N минут после блокировки (`0 = off`).
- **Тёмная тема** — переключатель в настройках, единая палитра `ModernTheme`.
- **Иконка трея** — бейдж-замок при активной блокировке.
- **Настройки** — прозрачность и позиция оверлея, режим, автозапуск, звуки, тач-барьер, тема, таймеры.
- **Тихие звуки** — короткий звук при блокировке/разблокировке (отключается в настройках и в трее).

## Как работает блокировка (важно)

- Пока залочено, LL-хук **проглатывает вообще всё**: Down и Up для букв, цифр, F1–F24, Tab, Esc, пробела, мультимедиа — и отдельно системные клавиши **Win L/R, Apps/Menu, Alt (SysKeys), Shift, Ctrl**.
- Блокировка **Up** так же важна, как Down: меню Пуск открывается по *отпусканию* Win, Alt+Tab/Alt+F4 завершаются по отпусканию — поэтому пропускать Up нельзя.
- Комбинация анлока отслеживается внутри хука по состоянию клавиш в любом порядке нажатия; сам chord проглатывается (`return 1`), чтобы браузер/редактор не получали нажатие.
- `RegisterHotKey` остаётся как fallback: работает для лока (когда хук не стоит) и как страховка анлока при срыве хука. Конфликт хоткея больше не закрывает программу — показывается предупреждение, трей продолжает работать.
- В режиме `Keyboard + mouse` блокируется **вся** мышь: движения, down/up, колесо, h-колесо, X-кнопки. В режиме `Keyboard only` хук мыши не ставится и мышь полностью жива.
- При `Lock()`/`RefreshHooks()` состояние модификаторов считывается через `GetAsyncKeyState`, поэтому зажатые до лока клавиши не ломают анлок.

## Честные ограничения Windows (не баги)

Даже идеальный `WH_KEYBOARD_LL` хук **не может** заблокировать:

- `Ctrl+Alt+Del` (Secure Attention Sequence),
- `Win+L` (блокировка рабочей станции),
- `Ctrl+Shift+Esc` частично, `Win+Ctrl+Shift+B`, кнопки Power/Sleep, UAC / Secure Desktop.

Это ограничение ОС — CatLocker честно показывает его в окне настроек и здесь, а не пытается «заблокировать».

Надёжность:

- Хук должен отвечать быстрее `LowLevelHooksTimeout` (~300 мс), иначе Windows молча снимает его. Колбэк минимальный, анлок постится в UI-поток через `SynchronizationContext`, а watchdog следит за heartbeat и переустанавливает хуки.
- Без прав администратора неэлевated хук хуже блокирует ввод в элевated окнах — для полного блока запускайте от админа.
- Тач/перо (`WM_TOUCH`/`WM_POINTER`) через `WH_MOUSE_LL` не идут — их ловит тач-барьер (невидимые topmost-формы на всех экранах).

## Установка

Вариант 1 — готовый exe из [Releases](../../releases) (self-contained, один файл, .NET не нужен):

1. Скачай `CatLocker.exe`, положи в `%LocalAppData%\CatLocker\`.
2. Запусти, в трее включи `Start with Windows`.

Вариант 2 — сборка из исходников:

Требования: Windows 10+, .NET SDK 8.

```powershell
dotnet build
dotnet run
```

Публикация одного self-contained exe (профиль уже лежит в `Properties/PublishProfiles`):

```powershell
dotnet publish -c Release -p:PublishProfile=PortableWinX64
```

## Структура проекта

- **`Program.cs`** — точка входа, single-instance через `Mutex` с обработкой `AbandonedMutexException`.
- **`CatLockerApplicationContext.cs`** — трей, меню, lock/unlock, таймеры auto-lock/unlock, watchdog, тач-барьеры, тема, иконки.
- **`InputLocker.cs`** — низкоуровневая блокировка: swallow-all клавиатуры, полный блок мыши, in-hook детект chord, `RefreshHooks()` для watchdog.
- **`UnlockHotkey.cs`** — настраиваемый chord: парсинг `Ctrl+Shift+L`, имена клавиш, guard.
- **`HotKeyManager.cs`** / **`HotKeyWindow.cs`** — глобальный хоткей как fallback; мягкий фол при конфликте.
- **`TouchBarrierForm.cs`** — невидимый фулскрин click-eater на каждый экран.
- **`TrayIconFactory.cs`** — иконки трея locked/unlocked с бейджем.
- **`OverlayForm.cs`** — top-most pill-баннер (`WS_EX_NOACTIVATE` + `WS_EX_TOOLWINDOW`).
- **`SettingsForm.cs`** — настройки: режим, хоткей, таймеры, оверлей, звуки, тач, тема.
- **`AppSettings.cs`** — загрузка/сохранение/нормализация (`%AppData%\CatLocker\settings.json`).
- **`StartupManager.cs`** — автозапуск через Registry.
- **`ModernTheme.cs`**, **`ModernButton.cs`**, **`ModernMenuRenderer.cs`** — единая мягкая тема + тёмный режим.
- **`LockMode.cs`** — режимы и тексты.
- **`LockSoundPlayer.cs`** — короткие WAV-тоны в памяти.
- **`NativeMethods.cs`** — P/Invoke.

## Дизайн

Единый мягкий стиль (`ModernTheme` — единственный источник цветов, все цвета — live-геттеры):

- акцент индиго-фиолет `#5B50E6` (светлая) / `#8E94F9` (тёмная), текст-акцент `AccentStrong` с контрастом не ниже 4.5:1;
- светлая тема: воздух `#F1F4F9` + белый; тёмная: спокойный slate `#1B222E` + `#272F3E`;
- пилюли и карточки: радиусы 8 / 14 / 18 / 20, волосяные бордеры;
- системных контролов нет: свой `SoftTrackBar` (дорожка + thumb с кольцом), owner-draw комбобоксы (`FieldBackground`/`FieldBorder`), нумерики в скруглённых обёртках, `ModernButton` полностью на токенах;
- hero всегда индиго-градиент `#5B50E6 → #8B5CF6`, бейдж — белая пилюля с индиго-текстом (читается в обеих темах);
- превью оверлея — на контрастной подложке `PreviewBackdrop`;
- трей-меню красится в обе темы, глифы пересоздаются при смене темы, чек — `AccentStrong`;
- в текстах нет `&` (везде `UseMnemonic = false`), сетка отступов 8px.

## Как безопасно улучшать программу

1. **Сначала меняй высокоуровневый код** — `SettingsForm`, `OverlayForm`, `ModernTheme`, `AppSettings`. В хуки лезь только с пониманием WinAPI hook pipeline.
2. **Не ломай аварийную разблокировку** — chord обязан детектиться и проглатываться внутри хука; после изменений проверяй оба режима.
3. **Настройки добавляй через `AppSettings`** — свойство → дефолт → `Normalize()` → UI → применение.
4. **Цвета — только в `ModernTheme.cs`**, он же переключает тёмную тему (все цвета — live-геттеры).
5. **Звуки** — `LockSoundPlayer`, громкость/частоты там же.

## Чеклист проверки

- `Win`, `Win+D/R/E/S/Tab`, `AppsMenu`, `Alt+Tab`, `Alt+F4`, `Ctrl+Esc`, `Ctrl+Shift+Esc`, `F1–F12` — блокируются (включая Up).
- `Win+L`, `Ctrl+Alt+Del` — осознанно не блокируются, показан варнинг.
- Хоткей разблокирует и не триггерит чужое приложение; смена хоткея в настройках применяется сразу.
- `KeyboardOnly` — мышь жива; `Keyboard+Mouse` — всё мертво + тач-барьер держит тапы.
- Зажатые до лока модификаторы не ломают анлок; рестарт после килла — без краша.
- Auto-lock по простою и auto-unlock по времени срабатывают; тёмная тема красит всё окно.
